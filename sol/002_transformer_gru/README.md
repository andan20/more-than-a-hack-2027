# 002 — Transformer → GRU

Откройте `experiment.ipynb` в Jupyter и выполните Run All. Нужны исходные tactical ATD/XML в стандартной папке data (или MTAH_DATA_DIR) и публичная разметка из evaluation/gt. Новые зависимости: только согласованный tqdm; установка автоматически не запускается.

По умолчанию CPU, 12 эпох диагностики (4 минуты обучения + 1 минута проверки), затем новая модель на всех пяти минутах и полный прогноз. Меняйте параметры в первой ячейке до запуска. Для другой конфигурации задайте новый RUN_NAME. Для ускоренной проверки разработчика задайте переменную окружения POSSESSION_SMOKE=1: всего два блока обучения, без финального обучения и полного прогноза.

Результаты: `local_review/experiments/002_transformer_gru/<RUN_NAME>/`. Прогресс виден через tqdm и progress.json, история — diagnostic_4min/history.csv и final_5min/history.csv, веса — last.pt. Checkpoint включает оптимизатор и состояние генератора PyTorch. Повторный запуск продолжает с завершённой эпохи, незавершённая повторяется. Не запускайте одинаковый RUN_NAME параллельно. Не загружайте чужие checkpoint-файлы.

Архитектура: 11 признаков на токен игрока/мяча, Transformer Encoder 2×64 (4 головы), CLS pooling, GRU(64), H/A/D. Нет идентификаторов треков и позиционных номеров токенов. Каждый кадр — множество. Пропуски маскируются, токен мяча остаётся явно наблюдаемым или отсутствующим. Геометрические флаги воспроизводятся из ATD; точки не удаляются. Вратарь — крайняя точка на глубине 0–16,5 м от своих ворот по длине поля. Флаги не являются истиной о роли игрока или офсайде.

Обучение совместное: CE + 0.05×L1 между вероятностями соседних кадров с одинаковой истинной меткой. TBPTT по 125 кадров без пересечения разделов; память переносится внутри последовательности. Проверка сбрасывает память. В полном прогнозе память сбрасывается на границе тайма. Фиксировано 12 эпох; validation не выбирает checkpoint. Статистики масштабирования не обучаются на проверке.

Публичные 5 минут содержат лишь 17 владений. Проверочная минута ранее использовалась в проекте: это диагностика, не независимый тест. Финальное обучение на всех 5 минутах оставляет нас без независимой оценки этого матча. Нет гарантий улучшения baseline. Код не читает private ground truth, события или видео.

Все данные, реконструируемые признаки, прогнозы, журналы и веса этого запуска остаются локальными. Веса полноценного обучения можно отдельно оформить как финальный модельный артефакт. Не публикуйте выполненные ячейки с данными. Для повторения результата используйте сохранённую конфигурацию, те же исходные файлы и версии окружения; CPU выбран для воспроизводимости.
