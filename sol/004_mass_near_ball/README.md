# 004_mass_near_ball: Комбинация движения массы и игроков около мяча
Запустите **Run All**. Прогресс показывает tqdm; результаты и промежуточный progress.json — в local_review/experiments/004_mass_near_ball.
Нейросети не используются. Все исходные точки сохранены, координаты не печатаются. Геометрическая эвристика — гипотеза о владении, а не правило футбола.

Перебор задан заранее в grid.json. Выбираем максимум spellF1 на первых 4 минутах, при равенстве macroF1, затем меньший номер варианта. Последняя минута оценивается только для выбранной конфигурации. В обоих случаях история алгоритма идёт с начала тайма: контекст до проверки разрешён, будущие кадры не используются. Первые 10 секунд тайма используются для определения направления сторон; это явно оговорённая калибровка, а не полностью потоковый старт.

На публичных 5 минутах всего 17 владений, а вариантов много: выигрыш на обучении ожидаемо оптимистичен. Проверочная минута ранее использовалась в проекте, поэтому она тоже не независимый тест. Не используйте её для нового массового подбора.

D определяется неизменённой эвристикой эксперимента 001: положение/движение мяча, медленное движение игроков, автоматические интервалы стандартов. Поэтому «только масса» означает источник выбора H/A; D всё ещё использует мяч и события. При отсутствии уверенного начального сигнала выдаём X; после первого решения сохраняем прошлую команду до подтверждения обратного сигнала.

Сначала запустите 003: этот ноутбук фиксирует его параметры массы, выбранные на тренировочном отрезке.

## Воспроизведение
Нужны исходные tactical ATD/XML и Smart Tagging в data либо MTAH_DATA_DIR. Гомография и видео не используются. Зависимость от sol/001_box5_vote100/config.json — фиксированный детектор D. Полный код находится в ноутбуке, новые библиотеки не устанавливаются.

При повторном запуске результаты этого эксперимента перезаписываются; старые эксперименты не меняются. grid_train.csv содержит все испытанные параметры и только тренировочные метрики. selected_config.json — победитель по обучению; metrics.json — отдельно train, validation, public_all. submission.csv — все 199319 кадров H/A/D/X, вне таймов X. Все выходы остаются в игнорируемой local_review. Не публикуйте выполненные ячейки с данными. Нет ручной коррекции ответов или доступа к закрытой разметке.

`selected_training_config.json` фиксирует параметры завершённого перебора на первых четырёх минутах. Полный Run All повторяет перебор, а не подбирает параметры по проверочной минуте.
