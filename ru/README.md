# Документация на русском

Полный перевод семи документов из локальной копии репозитория `more-than-a-hack-2027`. Оригинальные файлы не изменены. Числа, даты, обозначения, имена полей и команды сохранены по оригиналу; это перевод, а не обновление условий соревнования.

2. [DATA.md — данные, форматы и соответствие кадров](DATA.md)
3. [EVALUATION.md — метрики и оценивание](EVALUATION.md)
4. [SUBMISSION.md — формат решения и отправка](SUBMISSION.md)

6. [FAQ.md — частые вопросы](FAQ.md)
7. [OVERVIEW.md — общий обзор и календарь](OVERVIEW.md)

Ссылки между этими документами ведут на русские версии. Пути к коду и данным в тексте, а также команды запуска подразумевают корень исходного репозитория, а не папку `ru/`.

Термин ground truth переведён как «эталонная разметка»; possession — «владение», в том числе отдельный непрерывный отрезок владения; dead ball — «мяч вне игры».
